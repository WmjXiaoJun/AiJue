# V39：全流程 5 分钟特别节目（角色设定一致性测试）

> 用户：「视频生成的过程 你要按照我们设定好的角色才行，请你全流程做一下测试，生成一个 5 分钟的视频我看看」

## 1. 做法

用现有全流程产物 + 现场新生成一条角色宣传片，合成一支 **5:00 特别节目**：
- 片头 → 01 角色登场（12 位设定角色试镜，肖像驱动）→ 02 角色对戏（双人/三人正反打，肖像驱动）→ 03 角色宣传片（**现场新生成甜妹宣传片** + 老周宣传片）→ 04 3D 短片精选（模板流水线成片）→ 片尾字幕
- 统一规格：**1280×720 / 24fps / AAC**，章节卡 + 角色名牌 + 字幕

## 4. 角色一致性说明（重要）

- **肖像驱动**（第一至三章，试镜/对戏/宣传片）：H3 以角色**立绘**为参考图生成，脸/发型/服装/音色都来自设定角色 → 身份一致性最好
- **模板流水线**（第四章 3D 短片）：语义 brief 使用 cast 的**文字设定**（角色名/描述/风格），H3 由文字重建面孔，因此不是像素级同脸；但 cast、声音映射与模板合同均来自设定角色
- 若需要「全程肖像级一致」的 5 分钟连续新片：按每镜约 2 分钟 GPU 计，约需 40–60 镜 → **1.5–2.5 小时**，可后台跑
