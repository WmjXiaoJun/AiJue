# 成片 3.0：全动态镜头 + 口型 + 首尾帧 + 转场

## 目标（用户要求）
1. **每个出镜说话镜头都要有嘴形和动作**，不能只有个别人物是动态、其余是静帧。
2. **注意首尾帧**：H3 生成必须可控首帧（必要时尾帧），保证角色/构图连续、不换脸、不漂移。
3. **镜头与转镜**：镜头要有景别/机位设计，镜头之间有转场（xfade/whoosh 等），不能全是硬切静帧。
4. 参考开源库的成熟做法（ArcReel 交互/资产先行、OpenMontage pipeline/质检、Toonflow 画布/工作流），不复制 AGPL 代码。

## 技术路线
### A. 说话镜头（lip-sync 主路径）
- 输入：角色概念立绘（按景别合成的首帧） + **该镜头 TTS 音频**（每镜单独合成）。
- 模型：MiniMax H3 **ReferenceToVideo / ref2va** 工作流（05_ref2va_4step_sla.json）；ref_images=[首帧/立绘]，ref_audios=[TTS wav]。
- 输出：5.17s/768² 左右视频，画面角色按音频说话（口型跟随）；最终成片**静音 H3 自带音轨，使用原 TTS 音轨**。
- 若 H3 音频参考不能驱动口型 → 回退：H3 i2v 生成动作 + **Wav2Lip/LatentSync** 对口型（12GB 内可跑）；二选一以实测为准。

### B. 非说话镜头/反应镜头
- MiniMaxH3ImageToVideo，**first_frame = 该镜首帧，last_frame = 下一镜首帧或同图**（04_i2v_fl2v 工作流）。
- prompt 指定动作/运镜：轻微点头、缓慢推近、微微摇镜、眨眼、呼吸起伏；禁止大位移/换脸。

### C. 转场与镜头
- 时间线拼接由硬切改为 **xfade**（0.2–0.4s，可配置 10+ 预设）+ 转场 whoosh 音效；重点镜头用 match cut（上一镜尾帧 ≈ 下一镜首帧）。
- 静帧仅用于片头/片尾/花字卡/蒙太奇，不再用于说话镜头。
- 镜头景别：host=中景、guest=中近景、reaction=特写；首帧按景别构图（现有 pipeline 合成函数）。

### D. 流水线/平台
- 每镜：TTS wav → H3 动态 clip（cache 按 shot/语言/参数）→ 静音 → 时间线（xfade + 字幕 + BGM/SFX）→ final。
- Shot 记录：first_frame/last_frame 路径、h3_video_url、生成模式（audio_ref / fl2v）、状态。
- 前端：分镜台「动态」徽标、首帧/尾帧缩略图、单镜预览、批量生成动态；成片房动态版渲染。
- 保留静态版本作为回退/对比。

## 验收（ep_002 优先，然后 ep_001）
- ep_002（21 镜）：所有对白镜头均有口型+动作；反应镜头有动作；21/21 动态；转场可见（xfade）；时长 75.95±0.2s；黑帧 0；TTS 音轨对齐；英文版可同法生成（不同 TTS → 重新生成）。
- ep_001（52 镜）：41 条台词镜头全动态；3 角色都有嘴形；首尾帧连续；成片 299s。
- 抽帧验证：每角色说话帧嘴部差异（帧差>阈值）；转场帧序列；首尾帧对齐。
